# Logo explorations

`2026-11-13-style-studies.png` — six "picture showing through" treatments of the
St. Carlo shrine icon (Corpus Christi Church, Covent Garden; photo by AndyScott,
CC BY-SA 4.0, via Wikimedia Commons). **Exploration only**: these are derived from that
photo, so anything made directly from them inherits CC BY-SA. The final mark gets redrawn
from scratch in the chosen style.

## simple/ (2026-11-13)
Original vector drafts (not traced): halo, curly-head silhouette, shoulders, laptop, glowing ciborium (no cross),
lit only from the Eucharist. a = halo disc, b = halo ring, c = flat tones. Comparison: 2026-11-13-simple-profile.png.
Regenerate: python3 simple/generate.py simple

## Low-key presets (2026-11-13)
Made with ../../illustration/tuner.html (open it in a browser; sliders for Eucharist brightness/style, light position,
strength, spread, warmth, halo, edge gaps; "Download SVG" and "Copy settings"). Sheet: 2026-11-13-lowkey-presets.png.

## marks/ (2026-11-13)
Black-only logo directions (flat, one color), after deciding the tone-on-tone piece is an illustration
rather than a logo. Sheet: 2026-11-13-mark-directions.png. Regenerate: python3 marks/generate.py
Monstrance-compass hybrids (from 1a/1b): sheet 2026-11-13-monstrance-hybrids.png, SVGs marks/H1–H8.svg.
Regenerate: python3 marks/hybrid.py
